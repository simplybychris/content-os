# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Opis projektu

Content OS to system zarządzania treściami - od pomysłu przez drafty do publikacji. Projekt jest w języku polskim i przeznaczony do interaktywnej pracy z Claude Code.

## Przepływ pracy

```
Pomysły (content/ideas/) → Drafty (content/drafts/) → Opublikowane (content/published/)
                                       ↓
                          Repurposing (content/repurposed/linkedin/, content/repurposed/twitter/)
```

## Struktura katalogów

- `content/ideas/` - Pomysły na treści z priorytetami
- `content/drafts/` - Artykuły w trakcie pisania ze statusem ukończenia
- `content/published/` - Opublikowane artykuły (nazwa pliku: `YYYY-MM-DD-slug.md`)
- `content/repurposed/` - Treści dostosowane do social media (linkedin/, twitter/)
- `planning/` - Kalendarz redakcyjny i backlog
- `research/` - Materiały źródłowe i notatki
- `templates/` - Szablony treści

## Format plików

Wszystkie treści używają Markdown z frontmatterem YAML zawierającym:
- `status` - Aktualny stan (Pomysł/Draft/Opublikowany)
- `data-publikacji` lub `termin` - Data publikacji lub deadline
- `platformy` / `formaty` - Docelowe platformy i formaty
- `postep` - Procent ukończenia (dla draftów)

## Język i ton

Wszystkie treści i dokumentacja są po polsku. Przy tworzeniu lub edycji treści zachowuj język polski, chyba że zostaniesz poproszony inaczej.

Używaj tonu profesjonalnego, ale przystępnego - treści są kierowane do szerokiej widowni.
